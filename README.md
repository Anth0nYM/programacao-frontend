# Desenvolvimento web front-end

Repositório das disciplinas **TIN.7316 – Desenvolvimento Web Front-End (72 h/a)** e **TIN.0147 – Introdução à Programação Web (80 h/a)** do curso EMI técnico em informática, do Instituto Federal do Piauí – Campus Picos.

- **Professor:** Anthony Luz
- **Período letivo:** 2026/2
- **Turmas:** 1 e 2 "B" de informática

## Ementa

Aspectos históricos sobre a Internet e Intranet. Navegadores de Internet. Protocolos HTTP, HTTPS, FTP e UDP. Introdução à linguagem HTML5. Criação de páginas estáticas com HTML5. Atributos de texto. Inserção de imagens. Links. Tabelas. Formulários. Templates. Botões. Publicação de sites. Estilização de páginas com CSS3. Frameworks front-end. Responsive Web Design. Introdução ao JavaScript.

## Objetivo

Compreender os conceitos fundamentais do desenvolvimento de páginas web, utilizando HTML5, CSS3 e noções introdutórias de JavaScript para criar, estruturar, estilizar, publicar e aprimorar páginas estáticas, considerando boas práticas de organização, usabilidade e responsividade.

## Avaliação

- Provas escritas e práticas, listas de exercícios e práticas em laboratório.
- Desenvolvimento de páginas web (formulários, tabelas, menus, links e layouts simples).
- Projeto prático de uma página ou pequeno site estático.
- **Aprovação direta:** média semestral ≥ 7,0 e frequência ≥ 75%.
- **Exame final:** média semestral entre 4,0 e 6,9; nota final ≥ 6,0 para aprovação.
- **Reprovação:** média semestral < 4,0 ou frequência < 75%.
